# Changelog

User-visible changes in each release. Draft a section with
`tool/changelog.sh <version>`, then edit it for readers. Store notes live in
`whats_new/`.

## 1.0.0 - Unreleased

### Features

- A fresh look, with seven themes including two for accessibility, in light
  and dark.
- Onboarding and a splash screen on first launch.
- Find a doctor, pick a time and book in a few taps.
- See your upcoming and past visits, and reschedule or cancel them.
